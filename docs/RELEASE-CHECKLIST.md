## 代码和调试

- [ ] 检查最终可执行文件对应的编译设置和日志；没有把设置文件或文件名作为唯一证据。
- [ ] Unity：IL2CPP 插件 / AOT / 反射工作正常；实际 build report 不含开发、脚本调试、分析和测试标志。
- [ ] Unreal：实际 UAT 日志 / 构建回执显示 Shipping；平台配置和 Target 规则没有重新打开控制台等开发功能。
- [ ] 检查旧调试入口、测试菜单、跳关、无敌、穿墙、管理员按钮及隐藏快捷键。
- [ ] 对 Blueprint、场景、Prefab、第三方二进制插件另做人工检查；确认文本扫描未覆盖部分。
- [ ] 最终 depot 不带 `steam_appid.txt`、源码备份、Git 元数据、加密密钥或 `.steam-release-guard`。

## 资源与符号

- [ ] 散装音频、模型、贴图的每一项都有用途说明或调整记录；不为隐藏扩展名破坏加载。
- [ ] 在自己的发布副本上，用匹配引擎版本的工具检查可列出的档案目录和可读的资源内容，分别记录。
- [ ] Pak 索引加密的结果已实测；不把失败的列目录操作当作内容加密证明。
- [ ] 如果存在 IoStore，单独检查 `.utoc/.ucas`；此工具没有验证它们的加密状态。
- [ ] 若采用全资源加密，比较同一场景的加载时间、内存、首次启动和一次真实补丁的体积。
- [ ] 为相同二进制保留私有符号及校验清单；验证一次崩溃能被正确符号化。
- [ ] 使用本工具 `stage` 后，对实际准备上传的 release 目录重新检查，不只看原 build。

## Steam 与玩家体验

- [ ] DRM 选择和原因有记录，允许选择“不使用”；没有声称它能阻止所有盗版。
- [ ] 使用 Wrapper 时，已审查上传授权、输出和签名顺序；没有覆盖唯一原始 EXE。
- [ ] 从 Steam 私有测试分支重新安装，运行的是分发后的确切文件。
- [ ] 测试通过 Steam 启动、直接启动行为、Steam 未运行、离线模式和联网恢复。
- [ ] 测试旧存档迁移、新存档、云存档冲突、插件、多人联机与重连。
- [ ] 测试手柄 / 键鼠等目标输入；保护措施没有增加付费玩家的无故崩溃或阻塞。
- [ ] 一旦出现误报、插件不兼容或补丁异常，有已经演练的回退版本。
